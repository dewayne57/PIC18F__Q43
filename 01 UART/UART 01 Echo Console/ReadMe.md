# UART 01 Echo Console

## Overview
Demonstrates the use of the builtin UART peripheral for communication with 
another system.  This demonstrates writing output strings to the remote 
system, as well as accepting input from that system.

## Source Files
- main.c: Program entry point and demo loop.
- config.h: Device configuration bits and shared constants.
- config.c: System configuration and initialization.
- uart.h: UART data areas and function signatures/declarations.
- uart.c: UART implementation.
