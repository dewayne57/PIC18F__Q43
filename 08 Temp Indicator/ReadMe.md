# Temp Indicator Example Family

This family demonstrates internal temperature indicator usage and trend reporting.


## What It Is
Demonstration of how to sense temperatures with the Q43 family microcontrollers using 
the builtin temperature sensor on the microcontroller die, external thermistors 
(including linearization), and an LM75 sensor.

## What It Does
- Provides a relative measure of temperatures.
- Supports thermal trend monitoring without external sensors.
- Enables temperature-aware firmware behavior.

## Common Uses
- Thermal drift compensation.
- Over-temperature warning or derating logic.
- Environmental trend logging.

## Projects
- Temp 01 Internal Sensor
- Temp 02 Thermistor Linearlization
- Temp 03 LM75 Sensor

## Shared Goals
- Demonstrate reliable peripheral initialization.
- Show observable behavior with measurable outputs.
- Provide reusable firmware patterns for future projects.
